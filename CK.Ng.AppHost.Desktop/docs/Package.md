# CK.Ng.AppHost.Desktop

The Angular side of a desktop application (CK.AppHost.Desktop): the `ck-desktop-log-links` component shows the
"Last log" and "Open folder" links when the application runs with its window and writes a text log. Its axios
instance (`createDesktopAxios`) sends the requests as messages to the window when the page is served by an in-process
endpoint (`app://localhost`).

See the [README](https://github.com/signature-opensource/CK-Configurator/blob/stable/CK.Ng.AppHost.Desktop/README.md).
