# CK.Configurator.Catalog

The catalog of what can be configured in a CKomposable World: for a published profile and its feeds, what each package
declares (configurable types, configuration declarations, topology relations, client facts, TypeScript packages,
commands). Main types: `CatalogWorld`, `CatalogSources`, `CatalogSource`, `PackageAnalysis`, `CatalogCache`, `CatalogWorker`, `Catalog`.

See the [README](https://github.com/signature-opensource/CK-Configurator/blob/stable/CK.Configurator.Catalog/README.md).
