# CK.Configurator.Catalog

The catalog of what can be configured in a CKomposable World: what each package of a published profile and its feeds
declares.

For each package: its configurable types, configuration declarations, topology relations, client facts, TypeScript
packages and commands. Main types: `CatalogWorld`, `CatalogSources`, `CatalogSource`, `PackageAnalysis`,
`CatalogCache`, `CatalogWorker`, `Catalog`.

See the [README](https://github.com/signature-opensource/CK-Configurator/blob/stable/CK.Configurator.Catalog/README.md).
