# CK.IO.AppHost.Desktop

The commands of a desktop application (CK.AppHost.Desktop handles them): `IGetDesktopInfoQCommand` (whether the
application has its window and a text log), `IOpenLastLogCommand` (closes the current text log and opens it) and
`IOpenLogFolderCommand` (opens the folder of the text logs).

See the [README](https://github.com/signature-opensource/CK-Configurator/blob/stable/CK.IO.AppHost.Desktop/README.md).
