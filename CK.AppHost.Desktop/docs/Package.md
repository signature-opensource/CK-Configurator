# CK.AppHost.Desktop

The "DesktopWindow" feature of a party (`DesktopWindowFeatureDriver`): a native window (InfiniFrame, WebView2 on
Windows) shows the endpoint of the party's "HttpEndpoint" feature; closing the window stops the host.

See the [README](https://github.com/signature-opensource/CK-Configurator/blob/stable/CK.AppHost.Desktop/README.md).
