# CK.AppHost.Desktop

A CKomposable application as a desktop application: the "DesktopWindow" feature of a client application
(`DesktopWindowClientFeature`) and the bootstrap of its host (`CKomposableDesktopHost.Run`). A native window
(InfiniFrame) shows the client; closing the window stops the host, and a failure of the host is shown in the window.

See the [README](https://github.com/signature-opensource/CK-Configurator/blob/stable/CK.AppHost.Desktop/README.md).
